# Capri for iPhone

A native SwiftUI rebuild of the Capri Android app, using its own art, font, text and personality.

- Chat with Capri, several chats saved on the phone
- On-device AI with llama.cpp (GGUF models from Hugging Face), or a cloud provider with your own API key
- Voice in and out, web search, 15 languages

Every push to main builds an unsigned Capri.ipa (Actions, then Releases). Install with Sideloadly or AltStore.

Keep this repo private: the art, text and models belong to their owners.
